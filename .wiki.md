# Project Summary
This project is the web frontend for an AI Revenue Recovery system, providing a dashboard and recovery workflow UI for reviewing cases, managing recovery settings, and browsing/serving blog content (including prerendered routes and sitemap generation).

# Project Module Description
- AppShell (Recovery area): Provides shared layout for recovery-related screens, including core navigation and consistent page structure.
- Pages:
  - Index: Landing/dashboard view.
  - Cases: Case list and entry point to case detail.
  - CaseDetail: Detailed view for an individual recovery case.
  - BatchReports: Batch report creation/viewing entry for recovery outcomes.
  - SettingsPage: Configure recovery rules and thresholds used during recovery decisions.
  - AuthCallback / AuthError: Authentication flow handling and error presentation.
  - blog/BlogIndexPage and blog/BlogPostPage: Blog browsing and individual post rendering.
- Blog rendering and prerendering:
  - prerender/blog.js + utils: Generate static blog routes and content.
  - prerender/blog-sitemap.js: Build blog sitemap for discoverability.
  - prerender/blog-routes.js: Build blog route manifests for prerender.
  - components/blog/MarkdownArticle and BlogArticleLayout: Render markdown-based blog posts into consistent article layouts.
- UI component library (src/components/ui): Reusable styled UI primitives (buttons, dialogs, tables, forms, toasts, navigation, etc.) used throughout the app.
- Services and libs:
  - services/recoveryEngine: Recovery engine API/data access layer for case recovery actions and decision inputs.
  - lib/api, lib/blog, lib/config, lib/utils: Shared helpers for API calls, blog utilities, configuration, and general utilities.
- Hooks:
  - use-mobile and toast helpers: Device responsiveness helpers and toast state/actions.

  - package.json: Dependency and scripts definitions for the frontend.
  - vite.config.ts: Vite build configuration.
  - index.html: Vite HTML entry template.
  - src
    - App.tsx / App.css: Root app component and base styling.
    - main.tsx: Client entry bootstrap.
    - pages/: Route-level page components (Cases, CaseDetail, BatchReports, Settings, Auth, Blog pages).
    - components/
      - blog/: Blog article layout and markdown rendering.
      - recovery/: Recovery area shell and case table UI.
      - ui/: Reusable UI primitives.
    - services/recoveryEngine.ts: Recovery engine service integration.
    - lib/: API/blog/config/util helpers.
    - hooks/: use-mobile and toast hooks.
    - lib/utils.ts: Shared utilities for the frontend.
    - index.css: Global styles.
  - public/
    - favicon.svg: App icon.
    - robots.txt: SEO crawling instructions.
  - prerender/
    - blog.js, blog-routes.js, blog-sitemap.js, utils.js: Static prerender generation scripts for blog content.
  - tailwind.config.ts: Tailwind CSS configuration.
  - postcss.config.js / components.json: Styling/tooling configuration artifacts.
  - template_config.json: Frontend template configuration.

# Technology Stack
- TypeScript + React (Vite-based frontend)
- Tailwind CSS (with PostCSS)
- UI component primitives under src/components/ui
- Vite build system and lint tooling

# Usage
- Install dependencies: pnpm install
- Lint: pnpm run lint
- Build: pnpm run build
- Run the UI (development): pnpm run dev
